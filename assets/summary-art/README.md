# Ilustraciones originales de los resúmenes

Generadas el 14 de octubre de 2026 mediante la herramienta integrada de generación de imágenes. El logo institucional se incorpora desde el archivo original de Ben Carson; no se genera ni modifica con IA. Las explicaciones y rótulos se maquetan como texto seleccionable, separado de las imágenes.

Cada lámina contiene dos columnas y cinco filas. `scripts/summary_visual_design.py` selecciona cada figura mediante recortes de visualización dentro del PDF, conserva los originales y agrega una lectura didáctica. Las figuras son esquemáticas y no sustituyen las explicaciones ni representan protocolos clínicos.

Los prompts completos están en `prompts.json`.
