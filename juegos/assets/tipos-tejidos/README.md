# Tipos de tejidos

Las ilustraciones de este banco se crearon como recursos didacticos originales.

- `atlas-cuatro-tejidos.png`: panorama de los cuatro tejidos fundamentales.
- `tejido-epitelial.png`, `tejido-conectivo.png`, `tejido-muscular.png` y `tejido-nervioso.png`: recortes cuadrados de cada panel del atlas.

Los recortes se prepararon con margen de seguridad y la interfaz los muestra con `object-fit: contain`; por eso no se corta ningun elemento en celular ni en computadora.
